# HCL TECHNOLOGIES — README
---

## THESIS

HCL Technologies is a **high-quality compounder caught in a mid-tier trap.** Exceptional capital efficiency and stable cash generation are real. But growth is decelerating and margins are compressing because the underlying unit economics are constrained: headcount growth can't outpace wage inflation, utilization can't improve beyond 85%, and pricing power is weak (commoditization).

HCL's only escape from the mid-tier squeeze is a successful pivot to higher-margin specialty services (ER&D, AI, SaaS). This pivot is necessary but unproven.
